## Git

- Explain each git command in one sentence before running it.
- A commit is a "checkpoint". Save a checkpoint after every passing check, with a one-line message saying what changed and which checks pass.
- If this folder is connected to GitHub, push after each checkpoint.
- Never commit files larger than 10 MB, output or result files, build-output PDFs, passwords, or keys.
- Never run git reset --hard, git push --force, git clean, or anything else that deletes history or unsaved work, without first telling me in plain words what would be lost and asking me.
- Before going back to an older checkpoint, save the current state as a checkpoint first.
- The GitHub repository is private. Never make it public.
- If the sandbox blocks a git command, ask for my approval to run it outside the sandbox instead of stopping.
